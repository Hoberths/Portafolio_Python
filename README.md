# Proyectos Aplicados en Python 🚀

Este repositorio contiene una colección de proyectos modulares desarrollados en Python, enfocados en resolver problemas de negocio mediante automatización, extracción y transformación de datos (ETL), y desarrollo de interfaces de usuario. 

## 📁 Estructura del Portafolio
1. **[01_Gestor_Tareas_Web](./01_Gestor_Tareas_Web):** Arquitectura Cliente-Servidor (Flask).
     👉 [Ver aplicación en vivo aquí](https://gestor-tareas-hoberths.onrender.com/)
2. **[02_Reporte_Ventas_ETL](./02_Reporte_Ventas_ETL):** Pipeline de datos (Pandas, Matplotlib) y Business Intelligence.
3. **[03_Organizador_Archivos](./03_Organizador_Archivos):** Script de optimización de procesos (Pathlib).
4. **[04_Editor_Notas_GUI](./04_Editor_Notas_GUI):** Aplicación de escritorio (Tkinter, POO).
